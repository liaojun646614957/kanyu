# 看余 KANYU

输入生日，读一读你的出厂设置。中国年轻人向的趣味算命站，交互原型 + 可运行实现。

## 三个模块

| 模块 | 逻辑 | 成本 |
|---|---|---|
| 日柱人格卡 | 真实四柱排盘（儒略日 → 六十甲子 → 年月日时柱） | 纯前端，0 元 |
| 摇卦 | 真实三钱法六爻 → 六十四卦 → 变卦 | 纯前端，0 元 |
| 今日一抽 | 日期做种子的确定性抽卡（同一天结果固定） | 纯前端，0 元 |

三个模块全部不需要后端、不需要注册、不上传生日。

## 算法可信度

`src/lib/ganzhi.ts` 的实现已对以下基准校验：

| 输入 | 期望 | 实际 |
|---|---|---|
| 2024-01-01 12:00 | 癸卯 甲子 甲子 庚午 | 一致 |
| 2000-01-01 12:00 | 己卯 丙子 戊午 戊午 | 一致 |
| 1900-01-01 12:00 | 己亥 丙子 甲戌 庚午 | 一致 |
| 1995-03-15 14:30 | 乙亥 己卯 乙巳 癸未 | 与 sajutight 一致 |

六十四卦 `src/lib/gua.ts` 用「上卦 × 下卦」二维表（不是手写 64 项数组，避免错位），
对乾/坤/泰/否/既济/未济 六个卦做了上下卦对称校验，6/6 通过。

节气用低精度太阳视黄经公式求解，与天文台公布时刻误差约 6 分钟。
对「日柱」判定毫无影响；对月柱/年柱仅在立春、惊蛰等交节时刻前后数分钟内可能有分歧。

## 开发

```bash
npm install
npm run dev     # http://localhost:3000
```

## 技术选型

- Next.js 16 App Router（RSC）
- Tailwind CSS v4（`@theme` 令牌，无外部 UI 库）
- 零图表库：五行雷达是手写 SVG
- 分享海报：Canvas 2D 手绘（不用 html2canvas，40KB+ 且对现代 CSS 支持不稳）

## 已知范围

- 只做到「日柱」级完整文案，60 柱中已写 26 柱，其余走诚实的回退文案
- 没有真太阳时修正（需要经度 + 均时差）
- 没有合盘、没有 AI 解读、没有支付 —— 这些是第二阶段
